# 更换机械臂后的 CiA402 分阶段验收

软件零偏可用于每条机械臂建立独立坐标：
`q = direction × 2π × encoder_rev + zero_offset_rad`。
控制指令使用它的逆变换，重力模型使用转换后的实测关节角度。因此应将零偏保存在
每条机械臂的 profile 中，保持 URDF 和 MoveIt 的关节坐标一致。
参考摆放误差会直接进入零偏；稳定的编码器读数不能证明实物参考精度。

先按[零点校准说明](zero_calibration_cn.md)保存新臂配置并独立复查。
核对六轴身份、适配器、方向、实际负载和安装重力方向。更换机械臂不能继承另一条臂的
`calibrated` 结论。为调试另存 profile，修正不包含当前姿态的旧窗口；结构、身份和
参数检查完成后才设置 `validated: true`，整机运动验收完成前保持 `calibrated: false`。
这两个文件分别保存原始校准结果和调试参数，不覆盖原始校准证据。

## 重力补偿

独立轴测试和生产控制器都调用同一 URDF 重力模型，按实测六轴姿态计算：

```text
tau_ff[j] = clamp(G(q)[j] × gravity_compensation_scale[j], gravity_compensation_limit_nm[j])
```

未设置限幅时仍受 profile 力矩上限保护。方向和 `torque_scale` 在随后转换到电机单位时
应用，不应再次手动翻转重力符号。`tip_payload: null` 仅适用于无附加载荷。
J1/J6 在当前安装方向下的模型重力接近零；J2/J3/J4 的非零补偿需要验证。
不能将旧配置中 J3/J4 的零补偿直接当成可用的全臂参数，也不能因为理论值存在就
认定保持、摩擦和回程已经通过。

生产控制器已有的 `controller.gravity_startup_slew_rate_nm_s` 也可用于显式分阶段测试，
例如 `1.0` 表示按关节侧每秒 1 Nm 渐入重力前馈。先验证完整目标力矩，使用位置 PD
保持和零前馈使能，再逐步加入补偿；只有补偿达到目标并持续静止后才开始轨迹。
渐入期间保持原有 `0.003 rad` 漂移保护，最多等待 10 秒，超时退出。
未设置此参数时保持原行为；普通及历史固定诊断不采用新的渐入路径。

## 小步到扩大行程

构建独立测试程序：

```bash
./scripts/build.sh --packages-select hex_arm_controller \
  --cmake-args -DHEX_ARM_ENABLE_CIA402=ON -DHEX_ARM_BUILD_COMMISSIONING=ON
```

`hex_arm_commission --commission-axis` 默认仍限于 `0.03 rad`。
显式加 `--allow-expanded-motion` 后可进行最大 `0.25 rad` 的单轴往返试验。
总运动时长不超过 30 秒；整个正弦往返轨迹的峰值速度、加速度都必须符合 profile。
此模式额外要求全程跟踪误差不超过 `0.02 rad`，实测峰值位移与请求相差不超过
`0.005 rad`，其余五轴漂移不超过 `0.005 rad`。回程仍使用原有连续稳定门槛，
容差最多 `0.005 rad`。每轮记录控制循环采样中的跟踪误差、速度及力矩峰值。

显式调参模式允许**当前选中轴**的 Kp/Kd 最高为 200 Nm/rad、20 Nm·s/rad，
其余轴仍限于 80/4。普通试验和历史固定诊断仍保留 80/4 上限。
提高增益必须另存单轴测试配置、逐档验证，不会提高电机端的总力矩或 PD 力矩上限。
不能将多轴高增益 profile 用于这一单轴调参入口。

折叠参考恰在 J2/J3 名义限位时，编码器量化或失能回弹可能产生微小越界。
只有 profile 显式设置了 `measured_position_margin_rad`，且修正量不超过 `0.001 rad`，
扩大测试模式才允许把起始命令限制在最近的合法边界，并要求测试方向朝向行程内部。
日志同时保留实测起点和命令起点；位移/回程指标以命令起点为参考。
普通诊断保持原行为，命令限位不扩大。

使能前后保持检查、单圈边界、身份、CAN 状态和驱动力矩限制继续生效。
普通单轴试验也持续检查只有选中轴使能，以及六轴温度不超过 70°C、相对起点温升不超过 2°C。
一次成功只说明这一轴、这一姿态、这一负载和参数下的往返通过。

容器内的批量入口如下（以已完成小步往返的 J6 为例）：

```bash
python3 scripts/commission-cia402.py \
  --profile config/hardware/firefly_y6.cia402.can2.commissioning.local.yaml \
  --axis joint_6 --deltas-rad -0.015 0.015 -0.03 0.03 -0.06 0.06 \
  --duration-sec 24 --output-dir /tmp/arm-j6-trial-01 --allow-motion
```

停止所有其他 CAN 控制程序后执行。批量入口的首步不超过 `0.03 rad`，后续步长最多翻倍。
所有步骤均启用上述严格模式；每一步从当次实测位置往返，不是绝对位置命令。
每轮失能后的姿态可能变化，不能把多轮位移简单相加当成验收范围。

程序在开始前及每次退出后独立读取身份、失能状态、故障码、心跳解除和静止情况；
任一步运动或独立读取失败，就停止剩余步骤。输出目录必须不存在，保留 profile 快照、
二进制和脚本哈希、完整运动日志、独立读取 JSON 和 `result.json`。
超时或中断会通知控制器走正常停机流程，不会继续发送下一步。
该入口不会修改配置或自动设置 `calibrated: true`。

## 支撑轴与顺序准备

`--support-axes` 是另一个显式准入：命名的支撑轴保持命令位置，选中轴执行往返。
只有命名的使能轴可使用最高 200/20 增益；其余轴保持失能、仍限于 80/4。
控制器要求 `gravity_startup_slew_rate_nm_s` 位于 `(0,1] Nm/s`，以零重力前馈和位置 PD 使能，
持续监测反馈后渐入补偿。所有轴在使能阶段仍受 0.003 rad 漂移保护，稳定持续 1 秒后才继续。
驱动限幅在全部失能时写入并回读，实时使能状态必须与名单完全一致。

例如使用已核对的 J3/J4 配置，先做 5 秒保持，选中轴位移为零：

```bash
python3 scripts/commission-cia402.py \
  --profile config/hardware/firefly_y6.cia402.can2.j3-j4-support.local.yaml \
  --axis joint_3 --support-axes joint_4 --deltas-rad 0 --duration-sec 5 \
  --output-dir /tmp/j3-j4-hold-01 --allow-motion
```

`--prepare-supports joint_2:0.03 joint_4:-0.03` 可在选中轴试验前顺序移动两个已命名支撑轴。
每步是相对本轮起点的位移，固定 20 秒半余弦轨迹，最多 0.25 rad，遵守 profile 限速/加速度，
禁止重复轴和选中轴；所有端点在使能前检查。每步必须实际到达 0.005 rad 目标容差，
且连续稳定 0.5 秒；最多等待 5 秒。通过后，已运动轴沿用该目标容差保持原命令，
不会将实测位置重新定义为目标。尚未移动的使能轴仍保持 0.003 rad 误差限制，失能轴漂移限制仍为 0.005 rad。
选中轴往返成功后按逆序返回各准备轴；失败立即进入确认失能，不继续后续动作。
因此发生失败后必须查看独立实测位置，不能假设所有轴已经按顺序返回。

即使 `--deltas-rad 0`，设置了 `--prepare-supports` 仍然会移动支撑轴。
这个入口会使能多个轴，但不启动 ROS、不改变零偏或标定标志，也不绕过生产控制器的标定准入。
批量入口为准备和逆序返回预留有界时间，仍在每次试验后独立回读六轴状态。
这些试验用于建立协同支撑证据，不能单凭一次保持成功就标记整机部署完成。

## 可选的运动前馈

每个关节可显式配置 `motion_feedforward`，缺省为关闭。例如：

```yaml
motion_feedforward:
  positive_nm: 0.25
  negative_nm: 0.5
  velocity_scale_rad_s: 0.0005
```

这是待辨识参数示例，不是通用的已验收值。控制器按**指令速度**计算
`tau_motion = magnitude(direction) × tanh(v_cmd / velocity_scale_rad_s)`，静止时为零。
它是当前负载、重力系数和传动条件下的经验运动辅助，不能单独视为已测得的纯库仑摩擦。
改变负载、重力系数或机械臂后必须重新辨识。

该项在关节侧与重力补偿相加，再做一次方向及力矩单位换算；叠加结果仍须通过原有软件力矩限幅，
不会因为各项分别合规就允许总量超限。重力渐入状态不累计运动前馈。
显式支撑轴验收模式按半余弦/往返位置曲线的解析速度计算该项，单方向幅值最多 2 Nm；
保持轴的指令速度为零。旧单轴及历史固定诊断拒绝含该项的配置，避免静默忽略。

生产控制器仅在客户端委托自动前馈时按插值器的指令速度加入该项；客户端明确发送的 `tau_ff`
（包括全零）保持客户端所有权，不额外叠加。生产准入仍要求已完成验收的本机配置。

## 进入 MoveIt 执行前

六轴方向、重力保持和双向跟踪分别通过后，还需验证从折叠姿态退出的顺序动作、
严格碰撞模型、多轴轨迹及连续保持。扩大 profile 的位置窗口只增加测试许可，
不代表整段范围已经验收。MoveIt 使用 `position_limits:=hardware` 取得 URDF 与本机
profile 的交集，同时保留慢速限制；不能以 plan-only 的碰撞例外作为真机执行验收。

离线回归：`python3 scripts/test-commission-cia402.py` 和 `./scripts/test.sh legacy`。
