## 使用当前真机入口

在本机仓库的图形终端执行：

```bash
HEX_ARM_CAN_IFACE=can2 ./scripts/docker-dev.sh up
HEX_ARM_CAN_IFACE=can2 ./scripts/docker-dev.sh real-launch moveit \
  /workspaces/hex_arm_ros2/config/hardware/firefly_y6.meow.can2.local.yaml \
  enable_execution:=true
```

启动时使用实测反馈，默认自动执行上述顺序。等待日志
`startup_ready reached and verified; controller continues holding` 后再使用 RViz 的
规划组 `arm`、`Plan` 和 `Plan & Execute`。当前是有限窗口，较大的末端拖动可能
超出可规划范围；可从关节目标附近的小幅移动开始。
只有一个应用负责发送电机控制，切换上位机/ROS 时先有序停止原控制端。

`startup_ready:=false` 表示使能后原位保持；不传 `enable_execution:=true` 则为观察/规划。
退出时在拥有 real-launch 的终端按 Ctrl-C，等待上述 VERIFIED 日志。
无需为了小摆放偏差反复重设零偏；超出入口容许范围时会在使能前拒绝。

| 关节 | 本机命令范围 rad |
|---|---|
| J1 | −0.03～0.01 |
| J2 | −1.572～−1.33；MoveIt 规划下界 −1.570 |
| J3 | 2.98～3.14 |
| J4 | −0.32～0.01 |
| J5 | −0.03～0.01 |
| J6 | −0.25～0.02 |

CAN 名称与物理通道仍可通过绑定工具选择；这台设备当前为 can2 / 通道 2。
