# Joint-coordinate convention in historical evidence

The immutable evidence files in this directory were recorded with the Firefly
Y6 v1 joint convention. For J3 only, convert a recorded value when comparing it
with the current v2 model:

```text
J3_v2 = J3_v1 - 1.57 rad
```

For example, the recorded folded value `3.14 rad` is `1.57 rad` in v2. The
evidence files themselves are intentionally not rewritten.
